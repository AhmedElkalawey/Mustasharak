الأسئلة الشائعة

هل أحصل على الكود المصدري كاملاً؟

نعم، ستحصل على جميع ملفات HTML, CSS, JavaScript جاهزة للتعديل والتخصيص.

هل أحتاج إلى خبرة برمجية؟

لا، سنزودك بدليل تشغيل مفصل خطوة بخطوة. وإذا واجهت أي صعوبة، الدعم الفني موجود لمساعدتك.

هل يمكنني تغيير الشعار والألوان؟

نعم، النظام قابل للتخصيص بالكامل. يمكنك تغيير الألوان والشعار بسهولة.

أين يتم تخزين بيانات الحجوزات؟

يتم تخزين البيانات بشكل آمن على منصة Supabase السحابية.
